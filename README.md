**CS250**
8-2 Journal Questions How do I interpret user needs and implement them into a program? How does creating “user stories” help with this?

To interpet user needs, I first try to see the project from the users perspective, and then ask clarifying questions to clear up blindspots. Creating user stories breaks down requirements into understandable, concrete scenarios that can be better understood and implemented. This way, I can focus on features that solve user problems.

How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?

By first planning out main features and then dividing the project into more manageable chunks, I can build it incrementally, which I find helpful. Agile processes like sprints and frequent collaboration/feedback sharing with teammates are easily implementable practices that can help keep the project on track and make sure that it stays adaptable. On a larger scale, other Agile practices and a more formal adoption of a framework like Scrum seems very helpful.

What does it mean to be a good team member in software development?

Being a good team member means communicating respectfully, clearly and openly, supporting other team members when needed, and being generally reliable. Listening to and giving feedback where needed is also important. Ultimately, maintaining a collaborative environment and a clear focus on the project is key to keeping the team enviornment in tact.
